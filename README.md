# TestPython: TriangleCalculator + pytest

Реализация класса `TriangleCalculator` (валидация сторон, площадь по формуле Герона, периметр, тип треугольника) и набор автотестов на `pytest`. Структура подготовлена для расширения Selenium- и API-тестами.

## Основные возможности

- Валидация сторон: неравенство треугольника, положительность, допустимые границы.
- Расчёт площади по формуле Герона.
- Расчёт периметра.
- Определение типа треугольника: равносторонний, равнобедренный, разносторонний.
- Обработка ошибок через исключение `SideException`.

## Структура проекта

- `app/triangle.py` — класс `TriangleCalculator`.
- `tests/triangles_test.py`, `tests/test_calculator.py` — автотесты (12 сценариев).
- `selenium_tests/` — заготовки под UI-тесты.
- `requirements.txt` — зависимости.
- `.gitignore` — исключения для временных файлов.
